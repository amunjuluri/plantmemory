## 4. Cost

Gemini cost per guide at the standard price ($1.5/M input, $7.5/M output incl. thinking): mean **$0.0242** (₹2.13); at today's introductory price $0.0121. Translation into two languages: $0.0205.

A plant with 10 breakdowns a day: about **$13.41 a month** (₹1180) in Gemini calls for guides and translations. Cloud Run scales to zero and Firestore holds a few MB per plant, both inside or near the free tier at this size.

## How this was measured

- Reports: [data/eval/benchmark_cases.json](../data/eval/benchmark_cases.json), 8 breakdowns covering an alarm code, no code, Telugu, Hindi, Telugu typed in English letters, a two-word report, a vague report and a machine with no manual.
- In process: the same pipeline as the API, each report 3 times after one warm-up, guides saved to a temporary copy of the knowledge base. Every Gemini call's tokens come from the API's usage metadata.
- Cloud Run: the deployed service, from a laptop over the internet, so times include the network. Guides it created were deleted afterwards.
- Gemini alone: same model and thinking level, one call per report, scored by the same code that checks PlantMemory's guides.

Limits: the data is synthetic and written by the team; n is small (one run moves a rate by several points); Gemini's latency varies by minute and region; the checks catch values with units and codes, not a wrong instruction in plain words (that is what the manager's review and QA are for).
